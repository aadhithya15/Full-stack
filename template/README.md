# HUE FIT — template/ (skin-tone system + universality masking)

30 model photos x 8 skin tones = 240 rendered variants, all sharing ONE mask set.

## Structure
  base/                 30 original template photos (768x1376 JPEG)
  fair/ light/ wheatish/ medium/ dusky/ deep/ warm/ cool/
                        30 photos each, pixel-identical to base/ except SKIN pixels.
                        Same model, same pose, same garment, same background.
  universality-masking/ 56 masks (white = garment, black = everything else).
                        Mask <PhotoID>-<piece>-mask.png belongs to photo <PhotoID>-<desc>.jpg,
                        which appears identically in base/ and every tone folder.

## Why one mask set works everywhere
Tone variants are generated by an HSV transform applied ONLY through a feathered
skin-alpha map (human-parser skin classes INTERSECT skin-colour gate; hair,
jewellery, garments and background are hard-excluded). Every non-skin pixel is
bit-comparable across all 240 images, so masks built once on base/ are valid for
every skin tone. Audit: mean abs diff outside skin <= 0.8/255 (JPEG codec noise
only); all >14-diff pixels are <=3px boundary ringing, zero recoloured regions.

## Usage
Recolour = replace pixels inside the mask (white) with the shop's target colour;
outside-mask pixels stay untouched. Masks are zero-skin/zero-background by
construction (10-check audit: strip-class purity, skin-colour audit, face/hands
zone clearance, silhouette containment, disjointness, morphology, format).

## Naming
Photo: `<PhotoID>-<desc>.jpg`  e.g. W1-lehenga-choli.jpg
Mask:  `<PhotoID>-<piece>-mask.png`  e.g. W1-choli-mask.png, W1-lehenga-mask.png
Multi-piece outfits carry one mask per garment piece — never merged.
